JOURNAL STRUCTURE
- journal.html: the Journal index page.
- journal/article-template.html: duplicate this file for every new article.
- assets/: place article photographs here.

HOW TO ADD AN ARTICLE
1. Copy journal/article-template.html and rename it, for example:
   journal/plum-tree.html
2. Replace all text in square brackets, and change the image path if needed.
3. In journal.html, copy the NEW ARTICLE CARD block.
4. Change its link, image, category/date, title and introduction.
5. Remove the Coming Soon card when the first article is published.

The main navigation already links to the Journal. No redesign is needed when articles are added.

Final editorial rule:
Only the Hero uses a large emotional headline. Every other section begins with a quiet label and moves directly into text, photography, reviews, or the booking action.

Brand and design guidelines are preserved as hidden HTML comments near the top of index.html and journal.html.
