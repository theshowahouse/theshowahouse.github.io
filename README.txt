The Showa House — Official Website v3.0

PURPOSE
The website is a discovery and branding tool. All reservations and pre-stay questions continue through Airbnb. No contact form is included.

NEW IN v3.0
- Canonical URLs and complete Open Graph / Twitter metadata
- Dedicated 1200 × 630 social-sharing image
- LodgingBusiness and Article structured data
- robots.txt and sitemap.xml
- First Journal article: “What Is a Showa House?”
- Search-engine-friendly titles and descriptions
- Existing Google Search Console verification retained

PUBLISHING
